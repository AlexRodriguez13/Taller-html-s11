* **Asignatura:** Diseño de sistemas en Internet

## Descripción de la actividad
Se desarrolló una página web personal en el archivo `index.html` implementando las etiquetas fundamentales de HTML:
1. Estructura principal con `<html>`, `<head>` y `<body>`.
2. Encabezados jerárquicos (`<h1>`, `<h2>`, `<h3>`) incluyendo el nombre completo.
3. Párrafo de presentación personal (`<p>`).
4. Lista desordenada (`<ul>` y `<li>`) detallando habilidades e intereses.
5. Imagen (`<img>`) y enlaces externos (`<a>`) hacia sitios y redes favoritas.
